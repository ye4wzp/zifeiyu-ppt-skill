# 视觉自检清单（P0–P3）

在 `render-png.mjs` 的渲染图上逐页检查，不要只读代码。P0/P1 必须修复后才能交付。

## P0 — 阻断交付
- 文字溢出槽位、被裁切、互相重叠
- 正文对背景对比度不足（<3:1 由校验器 R11 预警；3–4.5:1 区间与图上文字必须目检）
- 图片拉伸变形、加载失败（裂图）
- 事实错误：编造的数据、错误的日期/名称

## P1 — 必须修复
- 版式误用（如概念内容硬塞 KPI 版式）
- 密度失衡：一页塞了两个核心信息，或大片空到像没做完
- 中英混排无空格、标点错误（英文引号混入中文语境）
- 相邻两页同版式

## P2 — 应当修复
- 主题不统一（个别页换了强调色）
- 标题层级字数超建议值但未精简
- 图片主体被 cover 裁切到关键信息丢失

## P3 — 打磨项
- 文案节奏：标题句式统一（都用名词短语或都用动宾）
- kicker/meta 信息完整性
- 页码与目录条目对应

## 检查动作

1. 逐页看渲染 PNG（不跳页）。
2. 浏览器打开 index.html 用方向键完整翻一遍（确认运行时正常）。
3. Office 档：`node scripts/check-pptx.mjs <deck>/deck.pptx` 过结构门，再完成 pptx-export.md 的几何/字体比对。
4. 若本次改动触碰了 base.css / 版式骨架 / 主题：`npm run regress` 对金样基线必须全绿。
5. 技能本体有改动时：`npm run sync` 同步安装副本（`npm run sync-check` 查漂移）。
6. 交付后把本次新踩的坑写回 `references/failures.md`（现象 → 根因 → 修法 → 已固化到）。
