把 GRID 用在你的内容上

换一个 CSS 文件，十九个版式整套切换到瑞士语法。数据、工程、发布会类内容优先选它：真实数字配极细巨字，灰阶配唯一锚点，每一页都像仪表盘上的一格刻度。

01 · 适用

数据汇报、产品发布、技术分享——凡是数字能自己说话的内容。

02 · 禁用清单

渐变、阴影、圆角、双 accent、巨字加粗——出现任何一项即掉档。

03 · 换色

柠檬黄/柠檬绿/安全橙按许可对替换 token，全 deck 仍只有一色。
