## Global Constraints

- Canvas 1280×720 px; pt = px × 0.75; in = px ÷ 96.
- Text only inside `h1/h2/h3/p`; inline emphasis only unnested `<strong>/<em>/<span class="is-accent">/<span class="is-mark">`; no `<br>` — one heading element per line, grouped with `data-merge`.
- Inline style only `top/left/width/height/font-size/line-height` (+ `rotate`); every class must be defined in `assets/base.css` or `styles/keynote/style.css`.
- R4 font floor 16px; R16 export parity (no `transform`, single-layer shadow, uniform border, text slots without bg/border/shadow/padding). A gradient fill is only allowed on a `kn-fade` shape that carries `data-raster` (exported as its own alpha image; text stays native).
- Data roles (`kpi`, `bars`, `table`) use real, repo-verifiable numbers and carry a non-empty `data-source` text; bar width ∝ `data-value` (120 px per rule).
- Core copy comes verbatim from `docs/golden-content.md`; two-line golden titles join into one line on pages that use the shared centred head (`kn-title`); cover / statement / image-text / closing keep two lines. Style voice (Latin sub-line, kicker words) is C's own.
- Goldens validate at `0 errors, 0 warnings`. Validator R13 warns when `object-fit: cover` crops away more than 45% — every image is generated at its box's aspect (sizes below are 2× the box, or 1920×1080 for full-bleed).
- Golden imagery from `scripts/gen-art.mjs --palette "$DARK" --format jpg` with `DARK="#3a3836,#232224,#ffc21a,#0a0a0b"`; every `alt` starts with「示意图：」and every page that shows an image says 示意图 in its foot or caption. Alt wording by kind: light →「暗墙上的一束窗光」, horizon →「暗色远山与低悬的太阳」, arch →「暗色立板与一块暖黄」, field →「暗场里的暖色光晕」.
- **C grammar:** near-black page (`--bg #0a0a0b`), white + grey type; warm yellow (`#ffc21a`) **at most once per page** — one `kn-kick`, one `kn-ac` figure/word, one `is-accent` span, or one `kn-acbg` fill. One point per page, big type centred. Content pages use the shared head: `kn-semi kn-title` (top 72, 56px, centred, ≤18 字) + `kn-sub` (top 156, 22px grey, centred; Latin voice line). Content zone 236–624. Foot at 672: `kn-note kn-source` left「来源：……」(data pages add `data-source`), `kn-note kn-pageno` right, plain number. Full-bleed photo pages put their text bottom-left at left 80 over a `kn-fade` + `data-raster`, caption via `kn-note kn-capl`. Dark rounded cards `kn-card` (#1c1c1e, radius 24) export as native round rects; a photo inside a card uses the same box + `kn-card` radius.
- `fonts.office` maps every rendered family (Source Han Sans SC → YaHei / YaHei Light, Inter → Segoe UI / Segoe UI Light, PingFang SC → YaHei / YaHei Light); export prints no `warn:` line.
- Every commit message ends with exactly `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- Never commit `decks/` or `.superpowers/`, renders, `.export-crops`, `.regress`, deck.pptx.
- Work on branch `style-keynote` (already checked out; specimen committed).

```python
import sys, glob, os
from PIL import Image, ImageDraw
renders, lo, out = sys.argv[1], sys.argv[2], sys.argv[3]
nums = [int(n) for n in sys.argv[4:]]
w = len(os.path.basename(glob.glob(lo + '/p-*.png')[0])) - 6   # pdftoppm pads page numbers to the page count's width
sc = 0.6; W, H = int(1280*sc), int(720*sc); pad = 24
sheet = Image.new('RGB', (W*2 + pad*3, (H + pad) * len(nums) + pad), (200, 60, 60))
d = ImageDraw.Draw(sheet)
for i, n in enumerate(nums):
    y = pad + i * (H + pad)
    a = Image.open(f'{renders}/slide-{n}.png').convert('RGB').resize((W, H))
    b = Image.open(f'{lo}/p-{n:0{w}d}.png').convert('RGB').resize((W, H))
    sheet.paste(a, (pad, y)); sheet.paste(b, (pad*2 + W, y))
    d.text((4, y), str(n), fill=(255, 255, 255))
sheet.save(out)
```

````python
# Regenerates styles/keynote/layouts.md: header + grammar + one entry per
# manifest layout (description + the golden <section> verbatim).
import json, re, sys
root = sys.argv[1]
st = f'{root}/styles/keynote'
man = json.load(open(f'{st}/manifest.json', encoding='utf-8'))
gold = open(f'{st}/golden/index.html', encoding='utf-8').read()
secs = {re.search(r'data-layout="([^"]+)"', s).group(1): s for s in re.findall(r'<section class="slide[ "].*?</section>', gold, re.S)}

STATUS = {
    'draft': '> 状态：draft · P2 样张阶段，已有 cover / kpi / process；其余核心角色未完成前，交付请用其他风格。',
}
GRAMMAR = '''## 版面语法

1. **一页一个重点**：近黑底，大字居中；内容页标题 56px 居中（`kn-semi`），封面标题 100px 左下。
2. **暖黄全页一处**：一个 `kn-kick` 小标签，或一个 `kn-ac` 数字 / 词，二选一；其余只用白（`--text-1`）与灰（`kn-grey` / `kn-body` / `kn-note`）。
3. **页脚**：top 672，左「来源：……」灰字（`kn-note kn-source`，数据页加 `data-source`），右页码（`kn-note kn-pageno`，只写数字）；封面不放页脚。
4. **深色圆角卡片**：`kn-card`（#1c1c1e、圆角 24），导出为 PowerPoint 原生圆角矩形；卡片里放照片时，`<img>` 用同一组类得到同尺寸同圆角，再盖一块同尺寸的 `kn-scrim`。
5. **照片上的渐变压暗**：`kn-fade` 必须带 `data-raster`——PowerPoint 画不出这种渐变，导出时单独截成带透明度的图片，文字仍是原生文本框。
6. **字体分工**：标题、标签用思源黑 600（`kn-semi` / `kn-kick`，Office 里是微软雅黑）；数字用 Inter 600（`kn-num`，Office 里是 Segoe UI）；正文与说明走系统字体（`kn-body` / `kn-note`）。
7. **配图**：金样配图由 `scripts/gen-art.mjs` 用暗调配色生成（`--palette "#3a3836,#232224,#ffc21a,#0a0a0b"`），alt 与页脚都写「示意图」。'''

DESC = {
    'keynote/cover': '封面。满版照片 + 全幅渐变压暗（`kn-fade` + `data-raster`）；左下暖黄小标签 → 两行 100px 标题（每行一个 h1，每行 ≤6 字）→ 一行说明。',
    'keynote/kpi': '数据页，一个数撑满一页。暖黄小标题居中 → 288px 巨大数字 → 粗体标签 + 一句说明 → 短细线 → 并排两个辅助数字与标签 → 页脚出处（`data-source`）与页码。三个数都必须真实；巨大数字 ≤3 位。',
    'keynote/process': '流程页。56px 标题居中 + 一行灰色副题 → 4 张 276×388 深色圆角卡片：左上编号、底部步骤名与说明（≤26 字）；最后一步的卡片垫一张照片（同圆角）并盖压暗层，它的编号是全页唯一的暖黄。',
}

out = ['# 发布会 · 暗场（keynote）版式注册表', '', STATUS[man['status']], '',
       '规则：整块复制骨架，只替换文字与图片路径；不得增删结构、不得改类名。骨架上的 `data-layout / data-role / data-merge / data-anim / data-source / data-value / data-label / data-chart / data-media / data-raster` 是导出与动画的声明，原样保留（说明见 `references/roles.md`）。金样：`styles/keynote/golden/`；金样文字来自 `docs/golden-content.md`。',
       '', GRAMMAR, '']
for lid, meta in man['layouts'].items():
    out += [f'## {lid} · {meta["role"]}', '', DESC[lid], '', '```html', secs[lid], '```', '']
open(f'{st}/layouts.md', 'w', encoding='utf-8').write('\n'.join(out))
print(len(man['layouts']), 'layouts written')
````
